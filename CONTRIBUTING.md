# Как сообщить о проблеме или предложить изменение

## Замечания и ошибки

Создайте issue по шаблону «Ошибка или замечание». В нём укажите ОС и вариант установки,
команду запуска, код выхода, вывод `--version` и `--build-info` и фрагмент отчёта или
таблицы с проблемным пунктом.

Не публикуйте пароли, ключи и содержимое `/etc/shadow`. Об уязвимостях сообщайте закрыто —
см. [политику безопасности](SECURITY.md).

## Запросы на изменение (pull request)

Pull request не принимаются: репозиторий на GitHub — публикация готового продукта, при
каждой публикации его содержимое заменяется. Предложения присылайте через issue.

## Версии

Каждое изменение продукта выходит новой версией; номер версии показывает `--version`.
