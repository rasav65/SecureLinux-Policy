# Правила общения

Репозиторий предназначен для замечаний по SecureLinux-Policy. В issue и обсуждениях:

- пишите по делу: что запускали, что получили, что ожидали;
- уважительно, без оскорблений и личных выпадов;
- не публикуйте пароли, ключи, содержимое `/etc/shadow` и другие секреты — ни свои, ни чужие;
- об уязвимостях сообщайте закрыто — см. [политику безопасности](SECURITY.md).

Сообщения, нарушающие эти правила, удаляются; повторные нарушения ведут к блокировке.
